# words2Voice-Demo-project
A Communication App for Children With Developmental Disabilities

About the Project

MyVoice is a full-stack communication application designed to help young children with developmental disabilities express their needs, feelings, and thoughts through words, phrases, and pictures.

The application provides a simple, accessible interface where caregivers can create and organize communication tools for children. Children can select images or words from a categorized word bank to communicate with their caregivers.

MyVoice was inspired by my background working with children and young adults with developmental disabilities and my passion for building technology that promotes accessibility, independence, and inclusion.

Features

User Authentication: Login and signup pages for users.

Communication Board: A child-friendly interface for selecting words and images.

Word Bank: Organized categories such as Colors, Numbers, and Feelings.

Caregiver Dashboard: A dedicated area for caregivers to manage communication content.

Simple Navigation: Easy-to-use pages designed with young children in mind.

Responsive Design: A layout designed for accessibility across different screen sizes.

How It Works

A caregiver accesses the application.

The caregiver adds or manages words, phrases, and images.

Communication content is organized into categories.

A child selects words or pictures from the communication board.

The selected content helps the child express a message to their caregiver.
